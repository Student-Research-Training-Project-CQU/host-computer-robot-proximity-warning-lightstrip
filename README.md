## 🚀 功能简介

这是一个基于 Qt 开发的雷达上位机软件，用于：
1. 实时显示 LD14P 激光雷达点云数据
2. 检测障碍物距离并显示在障碍物视图中
3. 配置灯带的四级预警阈值
4. 配置灯带小灯数量
5. 与 STM32 下位机进行通信，同步配置

### 主要功能

| 功能模块 | 说明 |
|---------|------|
| 📡 串口助手 | 配置串口、收发数据、显示数据 |
| 🌌 点云视图 | 实时显示激光雷达扫描的点云数据 |
| ⚠️ 障碍物信息 | 四个方向的障碍物距离和颜色显示 |
| 💡 灯带阈值 | 配置预警阈值和小灯数量，发送到下位机 |

---

## 🔧 通信协议

### 串口参数
| 参数 | 值 |
|------|-----|
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |
| 流控 | 无 |

### 阈值配置帧（上位机 → 下位机）

| 字节位置 | 字段 | 数据类型 | 说明 |
|---------|------|---------|------|
| 0 | 帧头 | uint8 | 0xAA |
| 1 | 命令码 | uint8 | 0x10 |
| 2-3 | 阈值1 | uint16 | 安全边界（mm），小端序 |
| 4-5 | 阈值2 | uint16 | 注意边界（mm），小端序 |
| 6-7 | 阈值3 | uint16 | 警告边界（mm），小端序 |
| 8 | LED数量 | uint8 | 小灯总数（1-255） |
| 9-13 | 保留 | uint8[5] | 填 0x00 |

**总长度：14 字节**

### 响应帧（下位机 → 上位机）

| 内容 | 说明 |
|------|------|
| "OK\r\n" | 配置成功确认 |

## 📦 环境配置

### 系统要求
- Windows 10/11 或 Linux
- Qt 6.x (MinGW 64-bit)
- C++17 编译器

### 依赖
- Qt Widgets
- Qt SerialPort
- Qt Core
- Qt GUI

### 编译步骤

1. **打开项目**
   ```bash
   cd HostComputerForSRTP
   ```

2. **使用 Qt Creator 编译**
   - 打开 `HostComputerForSRTP.pro`
   - 选择合适的 Qt 版本
   - 点击「运行」或「构建」

3. **命令行编译**
   ```bash
   qmake HostComputerForSRTP.pro
   mingw32-make
   ```

## 🎯 使用说明

### 1. 串口连接
1. 连接 USB 转串口设备
2. 点击「刷新」按钮
3. 在下拉框中选择正确的串口
4. 点击「打开串口」

### 2. 查看点云
- 雷达数据会自动显示在「点云视图」标签页
- 点颜色根据距离动态变化

### 3. 查看障碍物
- 在「障碍物信息」标签页查看四个方向的距离
- 障碍物会以颜色显示（绿/黄/橙/红）

### 4. 配置灯带
1. 切换到「灯带阈值」标签页
2. 拖动滑块或输入数值调整阈值
3. 设置小灯数量
4. 点击「发送到下位机」
5. 等待下位机回复 "OK\r\n" 确认

## ⚠️ 注意事项

1. **串口连接**
   - 必须打开串口才能发送配置
   - 确保波特率为 115200

2. **阈值配置**
   - 必须保持阈值1 > 阈值2 > 阈值3
   - UI会自动限制输入范围

3. **LED 数量**
   - 支持 1-255 个小灯
   - 超出范围时会自动限制

4. **下位机响应**
   - 发送后需要下位机回复 "OK\r\n" 才算成功
   - 500ms 超时未收到则显示失败
